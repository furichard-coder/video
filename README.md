# SceneryWalker 素材整理 App

這是剪接 App 的可驗收垂直切片。它負責選擇、排列及預覽影片／照片，並可產生串連或 Intro 預覽；不建立正式 Master、不做多軌 Timeline 剪輯，也不改寫或刪除來源檔。完成的正片預覽可由使用者確認後透過 YouTube 官方 API 上傳到已核對的頻道，或安全交接到 BiliBili／TikTok 官方投稿頁。只有使用者主動執行 AI 時，才會送出低解析故事板與故事背景；字幕的素材語音分析預設關閉，只有另行勾選才建立及送出短音訊。

目前版本：v0.42.0。

- 網格影片卡的「以外部播放器開啟」左鍵會立即依副檔名路由開啟唯讀意圖原檔；右鍵、鍵盤選單鍵或 `Shift+F10` 才開啟 proxy／原檔選擇視窗。第三方播放器的實際寫入行為不受 App 控制；放大預覽頁仍以明確選項視窗開啟。
- 指定播放器遺失或啟動失敗時會降級至 Windows 系統預設；再失敗則提示回到 App 內建 proxy，不會卡住 UI。
- 每張影片卡可建立多個不重疊的「音量區段」；範圍限制在目前 IN／OUT，音量固定 0%–300%。新專案素材原音預設為 100%，既有 manifest 的有效 80% 等數值會保留；未另外指定的區段使用專案預設。片段、音量或安插已有設定時，卡片按鈕會以不同高對比顏色顯示。
- 放大影片預覽提供可拖曳／點選的 10 ms 播放頭、毫秒時間顯示與穩定播放／暫停；可直接把目前播放位置設為正片排除區段的起點或終點。
- 每支影片可建立多個非破壞性「正片排除區段」；開始／結束限制於 IN／OUT，保存時自動排序並合併重疊或相鄰區段，也可單筆刪除或一鍵清除。
- 正片輸出會把 IN／OUT 扣除排除範圍後展開成連續保留子片段，不插入黑畫面或靜音占位；音量 automation、轉場、直式模糊、BGM 與字幕時間基準都使用實際保留片段。
- 全部有效範圍被排除的素材仍留在網格與來源 manifest，但不參與正片輸出；正片無保留片段時輸出按鈕安全停用。Intro 不受 Main 排除範圍影響。
- IN／OUT 縮短時，超出範圍的音量區段會安全裁切或移除，並在卡片顯示實際調整筆數。
- 補充匯入的素材逐一詢問放在最前、最後、指定素材前／後或待決定區；待決定素材不進入串連輸出。
- 網格卡片可用滑鼠左鍵長按後任意拖曳前後順序；拖動時 01、02…序號即時更新，放開後保存為 `timelineOrder`。上移／下移按鈕仍保留供鍵盤與精確操作，Main process 在輸出前再次核對。
- 9:16 素材會結合 ffprobe display rotation 判斷方向；16:9 輸出保持中央等比前景，左右使用同來源放大模糊填滿。
- 可加入一首或多首唯讀 MP3 配樂，設定 timeline、source IN／OUT、淡入淡出、順序及 0%–300% 音量；BGM 預設為 35%。多首曲目可依清單連續排列，並套用於正片與 Intro。
- 可混合加入多個 YouTube 連結作為來源／權利待確認參考，但 App 不會任意把 YouTube 影片轉下載成 MP3；每筆連結必須由使用者確認具使用權，再指定自有、已授權或透過 YouTube Audio Library 正式下載的本機 MP3 才能輸出。待確認或離線項目會安全阻擋輸出。
- 串連與 Intro 會混合片段原音和 BGM，最後套用 0.95 peak limiter；300% 是數位增益上限，不代表主觀響度三倍，也不保證無失真素材能被修復。
- AI 字幕預設直接用低解析故事板與專案主題／地點／故事背景建立知識型介紹，內容可涵蓋畫面直接相關的地方特色、歷史文化、自然生態、森林養護與環境保護；語音轉錄／說話者分段預設關閉，只有勾選「同時分析素材語音」才執行。
- 字幕頁採類 YouTube Studio 的逐項審核：同步 proxy 影像、時間、文字、說話者、畫面／事件／人物／地點證據、相關分數與警告均可核對；草稿可修改、確認或排除。
- 只有已確認 cue 能透過原生儲存視窗原子匯出 UTF-8 `.srt`；AI 草稿不會自動發布或輸出。
- 影片順序或 IN／OUT 改變後，字幕會標記需要複核；逐項確認並保存後，可在串連輸出永久嵌入一至兩種字幕。可選繁中、英文、簡中、日文、韓文，並分別設定位置、字級與自動換行。
- 「AI 帳號／故事」設定可保存多個 OpenAI API profile 並切換；API Key 由 Electron `safeStorage` 使用 Windows OS 加密並與專案分離。知識型字幕在 API 不可用時可透過本機 Codex 執行程式安全使用 ChatGPT 登入；App 不讀取或複製憑證。語音辨識與字幕翻譯仍不共用此備援。
- 故事背景的主題、人物、地點、故事／劇本／特色說明與觀眾承諾都有麥克風輸入；預設繁體中文、可切換英文。單次最多 120 秒／25 MB，辨識完成後不保存錄音檔；也可隨時用 Windows `Win+H` 輸入。
- OpenAI 429 錯誤會分開顯示 API project 額度／支出上限或暫時速率限制，並保留安全的錯誤代碼與 Request ID，不再把所有情況合併成同一句話。
- 非繁中字幕先以目前 OpenAI API profile 發出 `store: false` 的全新 Responses 請求；失敗時才用另行設定、Windows 加密保存的 Google Cloud Translation Basic v2 API Key。這不是 ChatGPT 網頁對話，也不能沿用 Codex 登入額度或 YouTube OAuth 憑證。
- 預設視覺模型為 `gpt-5.6-terra`，轉錄模型為 `gpt-4o-transcribe-diarize`；知識型字幕啟用 OpenAI API 與 Codex／ChatGPT 登入兩條實際路徑，其他 AI 仍只保留未啟用的擴充方向。
- schema 1–12 manifest 會自動遷移到 schema 13；舊照片安插資料會轉為通用素材安插，既有通用安插會補上來源位置，並保留照片時間、快門聲、字幕、音量、片頭與既有編輯欄位。未知或損壞 schema 會停止且不取代目前專案。
- 完成或取消後安全保留的 MP4 可直接依 `.mp4` 外部播放器設定播放。完成的正片串連預覽可透過使用者自己的 Google Desktop OAuth client 上傳至核對過的 YouTube 頻道，預設不公開、可改私人。
- 「平台上傳設定」會顯示 YouTube 的實際連結狀態、頻道名稱與頻道 ID。登入使用 Google 官方 OAuth 網頁；App 不提供帳號密碼欄位，也不讀取、顯示或保存 Google／YouTube 密碼，只保存 Windows 加密的授權 token。
- BiliBili／TikTok 採官方投稿頁安全交接：App 會複製完成檔路徑、在檔案總管選取 MP4 並開啟官方投稿頁；使用者仍需在平台內登入並確認標題、分區／隱私、版權及最後發布。未取得平台開發者應用與核准 scope 前，不假裝已完成自動 API 發布。

## 資料位置與安全

專案 manifest、一般使用偏好、最近使用資料夾、preview cache、預覽成品索引、Intro／AI story analysis cache、AI provider 設定、YouTube 設定與外部播放器設定放在 Electron `userData` 目錄，而不是來源資料夾。麥克風短錄音直接在記憶體中送出辨識，不落盤為永久錄音。AI API Key、YouTube OAuth client secret 與 refresh token 另存為 OS 加密檔，不會進 `.swproj`、renderer、一般偏好、預覽成品索引或分析結果；平台帳號密碼始終只輸入官方登入頁。AI 呼叫只上傳本次候選的短音訊、低解析故事板與使用者填寫的故事背景，不上傳完整原始影片；`store:false`，但實際 API 資料治理仍依帳號與 OpenAI API 政策。使用者另存的 `.swproj` 也採同資料夾唯一 partial＋可恢復替換，只有原生儲存／開啟視窗選定的路徑可讀寫。Renderer 不取得 Node 或任意檔案系統權限；只能透過白名單 IPC 操作資產 ID 或持久化的預覽 job ID。MP3 路徑只能由原生選擇視窗加入，後續 IPC 不能改寫成任意路徑；YouTube 參考連結不會觸發任意下載。外部播放 IPC 也只接受資產 ID 與 `PROXY`／`ORIGINAL`；預覽檔案庫只登記 App 實際產出或使用者用原生視窗明確選取的 MP4，Main process 會在播放或投稿前重新驗證絕對路徑、存在性與檔案類型。從預覽庫移除只刪除索引項目，不會刪除 MP4。素材安插只保存 asset ID、時間、插入影片 IN／OUT 與原順位，不改寫來源。封裝時只有 SHA-256 符合既定值的沙丘快門聲會被複製到 App 自有資源，並附來源與授權紀錄。MP4、SRT 與 AI 設定同樣先寫唯一 partial；一般成功後才完成，使用者取消 MP4 時則以 FFmpeg 的安全結束與 ffprobe 驗證決定是否保留較短成品。Preview 永遠是衍生檔，不能作正式 Master 來源。
