# ADR-0023｜片頭時間自動擴充與相鄰檔名顯示優先序

日期：2026-09-06

## 決定

- 使用者從網格片段時段勾選加入片頭時，先把專案目前的 `introTargetDurationMs` 增加新片段長度，再提交新的片頭清單。
- 擴充仍受既有 `INTRO_MAX_DURATION_MS = 180000` 約束；如果片頭實際總長即使擴充到 3 分鐘仍放不下，阻擋加入並明確提示，不建立部分片頭引用。
- 加入成功視窗顯示 Main process 回傳的實際順位及更新後時間上限。
- 網格標題依目前排序取得前、後相鄰檔名。相鄰檔名的前綴及可辨識年份／日期全部一致時，使用尾端省略策略，優先保留時間或流水號；任一相鄰簽名不同時使用前端省略策略。
- 第一張與最後一張只比較唯一相鄰項；沒有相鄰項時保留檔名前端。完整檔名永遠保留在 `title` 與卡片無障礙名稱。
- 網格 metadata 保持兩行、每行兩欄；只壓縮間距，不降低 v0.22 提高後的可讀字級。

## 理由

片頭總長欄位是使用者目前的目標，不應在明確手動加入片段時造成意外阻擋；但 3 分鐘仍是先前鎖定的產品安全上限。相鄰比較比固定從左或從右截斷更能兼顧相機批次檔名與不同裝置／日期素材。

## 相容與安全

- 不升級 manifest schema；只更新既有 `introTargetDurationMs` 與 `introSegments`。
- 來源影片、照片、metadata、proxy 及輸出檔均不修改。
- 顯示優先序只影響 renderer 的省略方向，不更名、不排序、不更改 manifest 檔名。
