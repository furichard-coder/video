# ADR 0039 — 專案週期浮水印

日期：2026-09-10  
狀態：Accepted

## 決策

- `ProjectManifest` schema 16 保存獨立 `watermarkSettings`，舊專案遷移時套用草漯沙丘地質公園的已驗證預設。
- 中文預設為「漫步／風光」左下兩行，英文預設為「SceneryWalker」右下單行；1080p 基準字級為 51／41 px，安全邊距 63 px，輸出時依高度等比縮放。
- 預設由 0 秒開始，每 360 秒開始顯示一次、停留 15 秒、淡入／淡出各 1 秒；文字與黑色底框不透明度為 82%／24%。
- 中文與英文可交換左下／右下，但不可置於同一角落。首次顯示、週期、停留、淡入、淡出、字級、透明度與邊距都由 Main process 再次驗證。
- 正片完成輸出與獨立片頭預設套用；Shorts 預設關閉並須明確勾選。固定片段檢查輸出不套浮水印。
- 浮水印是最後一段影像 filter，在可選字幕之後寫入新 MP4。來源與既有 MP4 永不覆寫，暫存文字檔在成功、失敗或取消後皆清除。

## 理由

前案的位置、大小、排列與週期已有實際成片證據，適合作為可回復的預設；專案層設定可避免不同影片誤用同一品牌節奏。Renderer 只提交結構化設定，不提交任意 font 或輸出路徑，維持既有安全邊界。

## 驗收

設定頁須可預覽左右下角、載入前案預設並保存。實際 FFmpeg filter 必須依 360p／480p／720p／4K 等比換算，並由整合測試確認輸出可播放、來源雜湊不變。
