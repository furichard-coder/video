# ADR 0018：知識型字幕、可編排片頭與色彩一致性

日期：2026-09-05  
狀態：Accepted（v0.18.0）

## 決定

- AI 字幕預設不抽取或轉錄素材原音，而是從正片代表畫面、專案主題、已知地點與故事背景產生可逐項審核的繁體中文知識型介紹草稿。
- 知識型字幕可說明地方特色、歷史文化、自然生態、森林養護或環境保護，但必須與當下畫面及已知背景直接相關；無法支持的知識不得捏造。
- 「同時分析素材語音」是獨立選項，預設關閉。勾選後才建立短音訊衍生檔並執行轉錄；畫面知識分析仍是主要流程。
- AI 草稿仍須逐項確認時間、影像與文字後才可保存、匯出或嵌入。OpenAI API project 無額度時安全停止，不以 Codex／ChatGPT 用量冒充 App API 可用額度。

## 片頭編排

- 片頭頁開啟時先顯示 0:03–3:00 的目標上限，預設 1:30；不自動啟動分析。使用者套用時間後才重新分析。
- 自動結果和手動加入的影片／照片共用最多 30 段規則；影片 3–22 秒，照片 3–7 秒。每段可調長度、IN／OUT、往前／往後與移除／恢復。
- 從其他資料夾加入片頭素材仍走原生選檔、唯讀匯入與 App cache；不改寫來源。

## 色彩與預覽

- 提供自然原色、暖陽金色、清透冷色、旅遊增豔、暖色增豔五個固定且可稽核的 FFmpeg 預設，不提供無上限自由參數。
- 色彩選擇保存於專案；片頭預覽與片頭輸出一致。使用者可勾選將同一設定套用正片，維持片頭／正片一致性。
- App 內影片控制列一律放在畫面容器外；影片、照片及縮圖使用 `contain`，依 display dimensions／rotation 完整保留 16:9、9:16 或其他原始顯示比例。

## 安全

- 色彩處理只存在於衍生預覽輸出，不改寫來源、proxy cache 或來源 metadata。
- 所有輸出維持唯一 partial、成功才完成；preview 不可作正式 Master 來源。
