# ADR-0013：網格影片縮圖左鍵直接外部播放

## 狀態

已採用，v0.14.1。

## 決定

- 網格中影片縮圖原本顯示「點擊放大」的主要左鍵動作，改為直接呼叫既有外部播放器服務，目標固定為唯讀意圖原檔。
- 路由仍依全域預設與副檔名覆寫選擇系統預設、VLC、Windows Media Player、MPC-HC 或自訂播放器；Renderer 只傳 asset ID 與 `ORIGINAL`，不傳入或拼接來源路徑命令。
- 播放器遺失或啟動失敗時，沿用既有安全 fallback 與可理解提示；只有服務回報使用 App 內預覽時才開啟原有放大視窗。
- 照片縮圖仍在 App 內等比例放大。網格 proxy 播放／暫停、其後的 App 內「放大」按鈕、IN／OUT、音量、素材安插、排序及移除行為不變。

## 理由

使用者把影片縮圖視為最直接的觀看入口，並已針對不同副檔名設定偏好的外部播放器。直接啟動可減少一次選擇或 App modal；保留 proxy 與其他控制則避免改變既有剪輯流程。

## 安全與相容性

- 不改 manifest schema、來源 metadata、proxy cache 或輸出。
- 外部播放器仍以安全參數陣列啟動；App 的唯讀意圖不等於能保證第三方播放器行為。
- 啟動期間暫時停用該影片縮圖，避免連點重複開啟；完成或失敗後恢復。
