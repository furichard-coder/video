# ADR-0051：字幕逐筆即時保存與相鄰時間位置移動

日期：2026-09-11  
狀態：Accepted

## 決策

字幕列的「確認」不是只改 Renderer 標記。按下後，App 會把畫面上最新的文字、開始／結束時間及確認狀態交給 Main process，通過既有字幕驗證並成功寫入專案後，才顯示已保存。全部確認、取消確認、Shift 複選操作及強制逐筆校對採同一契約。

每列保留原生 `textarea`，編號按鈕專責單選／Shift 複選，因此滑鼠可直接把文字游標放到任意位置。每列旁固定提供確認、刪除、上移、下移，不需要先開啟另一個編輯視窗。

字幕的輸出事實順序由時間決定，不能只交換陣列 index。因此上移／下移會交換同一 `INTRO` 或 `MAIN` 範圍內相鄰兩筆的輸出時間與來源錨點，並把兩筆改回 `DRAFT` 後立即保存。這代表字幕內容被移到另一個畫面位置後，必須重新人工確認。

## 未採用

- 只在 Renderer 改 `CONFIRMED`、最後再批量保存：容易讓使用者誤以為已經寫入專案。
- 只交換陣列順序但保留時間：領域驗證與 SRT 匯出仍會依時間排序，重開後看似「上移失效」。
- 移動後保留已確認：文字與畫面對位已改變，沿用舊確認會造成錯誤 QC 狀態。

## 安全邊界

所有操作只修改專案 manifest 的字幕清單。刪除仍有安全確認；影片、照片、MP3、Proxy、舊 SRT 與既有 MP4 都不會被改寫或刪除。
