# ADR-0003：來源裁切範圍與本機精彩片頭建議

日期：2026-08-29  
狀態：Accepted

## 情境

使用者需要在素材網格內直接播放每支影片、以左右把手指定起點與停止點，並希望 App 建議精彩片頭片段。App 目前沒有雲端模型憑證，來源不得被任意上傳或全檔逐格重掃。

## 決定

- `SourceAsset.previewRange` 保存每支影片的 IN／OUT 毫秒值。它只寫入 App manifest，不寫來源檔或來源 metadata。
- 網格播放使用 App cache 內的 H.264 proxy；正式建立串連預覽時，FFmpeg 仍從已驗證的原始來源依 IN／OUT 讀取。
- 將使用者文字中的「702p」依標準影像規格解讀為 720p（1280×720）；同時支援 360p、480p 與 4K。
- 精彩片頭第一版採本機抽樣式建議器，而非假稱有語意理解的雲端 AI。每支影片只在少數時間點隨機存取約 1.5 秒短區段，分析亮度、色彩與幀間變化。
- 分析結果以 `previewCacheKey + analyzerVersion` 建立 App 自有 JSON cache。來源 size／mtime 或分析器版本變更即失效。
- 建議必須包含 asset ID、IN／OUT、分數與理由；使用者可以預覽、調整、排序或排除。
- Intro 建議預設最多 8 段、總長不超過約 45 秒；人工調整後仍以 90 秒作輸出 gate。
- Intro 可重複使用同一來源的不同區段；輸出要求逐段驗證 asset ID 與實際來源時長。

## 後果與限制

- 無需 API key、素材不上傳，離線亦可產生快速且可重現的候選片段。
- 第一版分數不理解人物、地點、故事高潮或情緒語意，因此介面明示「人工預覽與 IN／OUT 決定優先」。
- 未來若加入本機視覺模型或經使用者授權的雲端模型，必須另立 ADR，說明模型、隱私、費用、失敗 fallback 與 cache 版本。
