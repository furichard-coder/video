# ADR-0022｜精簡網格、分秒輸入、片頭加入確認與循環播放

日期：2026-09-06

## 決定

- 網格檢視不重複顯示來源完整路徑與逐卡唯讀說明；程式上方保留全域唯讀狀態，清單檢視保留路徑供核對。
- 文字大小與整體 UI 縮放分開保存。整體縮放提供 75%、85%、100%、110%、125%、150%，並支援 Windows 常見的 `Ctrl`＋滾輪、上下鍵、加減號與 `Ctrl+0`。
- 來源時間欄位以分鐘和秒數兩格顯示；Enter 從起點分鐘移到起點秒數，再移到終點分鐘。領域模型與輸出仍使用整數毫秒。
- 來源時段、局部放大、畫質優化、加入片頭及 4K 時段輸出共用同一編輯區。使用者看見的放大量 0% 對應既有模型的 100% scale，避免破壞 schema 13 與舊專案。
- 新片段預設 0% 放大並勾選加入片頭。保存成功後顯示 canonical 片頭順位並讓使用者選擇留在原頁或前往片頭確認。
- 片頭最多 50 段；總長仍最多 180 秒，每段仍為 3–22 秒且受專案統一上限限制。
- 片頭播放預設整體循環：依 manifest 目前順序播放各段，最後一段再回第一段。單段循環只重播目前選取區段。暫停時不推進。

## 理由

這些變更縮短卡片高度、降低重複資訊，並讓長素材的時間輸入與片頭加入結果更容易核對。循環播放只改預覽控制，不改片頭 manifest、輸出順序或來源檔。

## 相容與安全

- 不升級 manifest schema；舊的 100%–400% scale 仍可讀寫及輸出，新 UI 只把它顯示為 0%–300% 放大量。
- UI 偏好只存於 App local storage，不進專案檔、來源 metadata 或輸出。
- 所有來源維持唯讀；沒有新增刪除、覆寫或來源路徑執行能力。
- 片頭加入先經既有 Main process 三層限制，再以回傳的專案內容顯示實際順位，不能只用畫面暫存冒充已保存。
