# ADR 0019：片頭均衡時長、SRT 匯入與代理復原

日期：2026-09-05  
狀態：Accepted（v0.19.0）

## 決定

- 每個專案保存 `introSegmentMaxDurationMs`，新專案預設 15 秒，可設 3–22 秒。改動後立即原子保存，因此同一專案下次開啟沿用最後設定，例如 12 秒。
- 套用統一上限或重新分析時，依「總片頭上限、每段上限、各來源可用長度」做公平分配；一般片段盡量等長，只有來源剩餘長度或照片 7 秒上限不足時允許較短。
- 舊 schema 10 專案若已有超過 15 秒的合法片段，migration 先保留既有內容並把上限設為既有最長片段（最多 22 秒），不在升級時靜默裁切。
- AI 片頭文字指示與優先基底影片屬專案故事設定。AI 仍只從來源素材選段，不把文字指示解讀成生成不存在的畫面；人物、事件與故事的人工確認仍優先。
- 4K 選項輸出實際 3840×2160 預覽。較低解析度來源保持比例放大，不能宣稱增加原始細節或取代正式 Master。

## SRT 匯入

- 只接受使用者透過原生視窗選取的 `.srt`，以 UTF-8 讀取，支援 BOM、CRLF／LF、逗號或小數點毫秒及多行文字。
- 匯入時驗證時間格式、正向區間、排序、重疊、空白內容、10 MB 大小與 10,000 cues 上限。既有字幕存在時先要求確認，再以匯入內容取代目前清單。
- 匯入只讀取來源 SRT；編輯結果保存於專案 manifest。每一 cue 仍可修改開始、結束與文字，時間線改變後沿用既有字幕複核 gate。

## 代理比例與復原

- `preview-v2` 的尺寸從旋轉修正後 display dimensions 計算，長邊限制在 854、短邊限制在 480，保持 SAR 1:1 與來源顯示比例，不因 UI 控制列裁切。
- 舊資產缺少 display dimensions 或 rotation 時，只對該資產重新 ffprobe，不掃描整個 RAW 資料夾。
- 代理以 H.264、30 fps、低負載設定建立；含音訊建立失敗時可重試無聲代理。UI 提供重新建立與用外部播放器查看唯讀原檔的 fallback。
- `.partial.mp4` 不是完成代理，永遠不得當作可播放 cache 命中或正式輸出來源。

## 歷史輸出

- 正片與片頭產出頁各自篩選 App 的持久化預覽成品索引，在頁面底部顯示檔名、時間、大小與解析度。
- 點擊歷史檔名時只以既有安全外部播放器路由開啟已登記的 MP4；Renderer 不傳任意路徑，檔案不存在或播放器失敗時顯示可理解錯誤。

## 安全與限制

- 不改寫或刪除來源媒體、來源 metadata、SOP、舊 release 或使用者現有 proxy cache。
- preview 永遠是 App 自有衍生檔，不得用作正式 Master 重建來源。
- 本版沒有把獨立 App 連線到 Codex／ChatGPT 登入 session；AI 仍使用另行設定且有 API project 額度的 OpenAI API Key。
