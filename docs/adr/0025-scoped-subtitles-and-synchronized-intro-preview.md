# ADR 0025｜字幕範圍與 480P 同步片頭預覽

- 狀態：Accepted
- 日期：2026-09-06

## 決定

字幕 cue 以 `timelineScope = INTRO | MAIN` 明確區分時間基準；舊專案缺少欄位時視為 `MAIN`。AI 請求帶入使用者勾選的範圍，只替換該範圍尚未確認的 AI 草稿，另一範圍與人工確認內容保留。

片頭字幕審核使用由最高品質來源重新編碼的 480P H.264 MP4 衍生檔。檔案只放在 App cache，cache key 包含預覽器版本、片頭片段、來源路徑／大小／修改時間／fingerprint 及相關畫面設定；代理不列入輸出歷史，也不能作正式 Master。為讓字幕審核不受尚未整理好的配樂影響，此代理不混入 BGM。

字幕文字在 Renderer 依播放時間疊加，因此使用者修改文字、位置、大小、顏色、陰影或外框後可立即看到，不需為每次格式調整重新轉檔。顯示格式與分析範圍存入 App 使用偏好，重新開啟沿用上次設定。

## 安全與限制

- 所有來源路徑只讀；FFmpeg 只寫唯一 App cache 位置及 partial。
- 取消、失敗或來源變更不會把不完整 proxy 當成有效快取。
- 480P 是審核代理；正式輸出仍回連來源並由輸出頁設定字幕燒錄。
- 本版不宣稱 proxy 放大為 4K，也不新增時間線、多軌剪輯或自動上傳行為。
