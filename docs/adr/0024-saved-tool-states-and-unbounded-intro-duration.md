# ADR-0024｜網格設定狀態與無硬上限片頭

日期：2026-09-06

## 決定

- 網格「片段／音量／安插」按鈕依 manifest 目前狀態顯示是否已設定。片段包含自訂 IN／OUT、Main 排除或局部放大；音量與安插以存在的保存資料判斷。
- 已設定按鈕除高對比色外，文字改為「已設片段／已設音量／已設安插」，並在 `title` 與 `aria-label` 標示已保存，不能只靠顏色傳達狀態。
- 移除 Intro 180 秒硬上限。`introTargetDurationMs` 只要求至少 3 秒，片頭清單不再因總長超過 180 秒而拒絕保存，分析器及輸出器也不再套用 180 秒上限。
- 180 秒改為 `INTRO_DURATION_WARNING_MS` 呈現門檻。實際片頭總長超過時，摘要與輸出列顯示紅色警示，但不停用輸出。
- 既有 50 段與單段 3–22 秒限制保留，因此本版仍有清楚且可預測的清單與單段邊界。

## 安全與相容

- 不升級 manifest schema；既有 90 秒或其他目標時間原樣保留。
- 超過 3 分鐘只是使用者明確要求的 UI 警示變更，不改來源、proxy、字幕、輸出順序或片段範圍。
- 網格狀態完全由已保存 manifest 衍生，未保存的視窗草稿不會冒充完成設定。
