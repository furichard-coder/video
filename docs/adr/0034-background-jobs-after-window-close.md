# ADR 0034：功能視窗關閉後保留背景工作

## 狀態

Accepted — v0.36.0

## 決策

AI 配樂搜尋、AI 片頭分析、AI 知識型字幕、字幕 480P 預覽與片頭／正片串連預覽由 Main process 持有工作與取消控制器。Renderer 的功能視窗只是檢視與控制介面；卸載 modal 不會觸發取消。使用者仍可從功能內的取消按鈕主動中止。

Main process 以短期 `BackgroundJobSnapshot` 廣播工作狀態到主畫面，包含工作類型、百分比、完成／失敗／取消與錯誤摘要。完成結果沿用既有安全保存：配樂結果與字幕草稿寫入專案，影片預覽寫入預覽檔案庫；來源媒體與 proxy 仍唯讀／衍生快取規則不變。

片頭分析結果另保存為 `introAnalysisResult`，重新開啟片頭頁時只提供「套用最近分析結果」的明確動作，不靜默取代手動順序、移除或既有片頭段。

## 安全邊界

- 工作只在 App 主程式仍存活時持續；完整關閉 App 或系統關機不承諾背景工作繼續。
- 取消仍會清理 partial 輸出；成功輸出仍使用既有唯一檔名與輸出歷史登錄。
- 背景狀態只保存短期記憶體快照，專案結果與媒體輸出才進行持久化。
