# ADR-0009｜全介面可讀性與網格直接排序

日期：2026-09-02  
狀態：Accepted

## 背景

素材網格包含檔名、時間、規格、編碼、來源路徑與多個操作說明。固定小字會讓使用者難以核對素材；只調整單一區域也會造成其他視窗仍不可讀。另一方面，上移／下移適合精確與鍵盤操作，但大量素材需要更直接的任意前後排序。

## 決定

- 在 sticky top bar 提供單一「Aa 設定」，使用 16、18、20、22 px 四級 root font size；全部元件字級以 `rem` 表達，所以網格、對話框、工具列與提示會一起縮放。
- 預設採 18 px「舒適」，偏好只保存於 renderer 的 App local storage。它不是專案內容，不會改變 `.swproj`、來源媒體、cache 或輸出。
- 網格卡片使用 280 ms 滑鼠左鍵長按 gate。長按後才能開始 HTML drag；拖過其他卡片時，renderer 以 asset ID 重排暫存 `timelineOrder`，因此卡面序號會即時更新。
- 放開時只把拖曳素材 asset ID 與最終索引提交至既有 `moveTimelineAsset` 白名單 IPC。Main process 負責寫入 canonical manifest、切換 `MANUAL_ORDER`、更新 timeline revision 與字幕複核狀態。
- 卡片中的移除、音量、照片安插、外部播放器、表單及影片控制不觸發長按排序；縮圖與卡片空白區可拖。既有上移／下移按鈕保留作為鍵盤可達 fallback。
- 保存失敗時顯示錯誤並重新載入 canonical project；不得把只存在畫面的順序宣稱為已保存。

## 影響

- 文字選項可立即預覽且跨 App 重開恢復，但不會跟著 `.swproj` 移到另一台電腦。
- 大字可能使小視窗更擁擠，因此設定頁明示可放大視窗或退回「清楚」。
- 拖動時只改專案排列，不搬移、重新命名或刪除任何磁碟檔案。
