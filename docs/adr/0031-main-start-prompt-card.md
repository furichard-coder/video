# ADR 0031：片頭與正片之間的強制提示頁

日期：2026-09-08  
狀態：Accepted

## 背景

使用者要求片頭與正片自動串接時，必須插入 3–7 秒的「正片將開始」提示頁，並參考草漯沙丘前案。前案的已驗證做法是以實際來源畫面壓暗，顯示兩行白字，前後各使用 0.3 秒疊化。全域轉場 SOP 則要求轉場節制、不得為補 handles 偷製造一般旅程連續畫面。

## 決定

- 只有 `purpose=CONCAT` 且 `prependIntro=true` 時加入提示頁；Renderer 必須先讓使用者確認設定，Main process 再做第二次範圍與文字驗證。
- 預設為 3 秒、62% 黑色半透明遮罩、兩行白字與 `DISSOLVE`。使用者可設 3–7 秒、兩行文字、各自行距／字級、30%–85% 遮罩，以及 `DISSOLVE`、`FADE_BLACK` 或 `HARD_CUT`。
- 背景重讀第一個正片片段的原始唯讀來源，不使用 proxy 當輸出來源；短於提示頁時只在這個明示的標題頁內延展末格，不用來偽造旅程連續性。
- 提示頁本身使用靜音底。既有 BGM 若勾選則依整體輸出時間線繼續混入，最後仍經 0.95 peak limiter。
- FFmpeg 文字採一次性 UTF-8 text file，filter graph 仍採 v0.30.0 的 `-filter_complex_script`。所有暫存檔在成功、錯誤或取消後清理。
- 插入提示頁後，同步平移正片字幕輸出時間；片頭字幕時間不變。
- 設定存在一般 User Preferences，不修改 project manifest schema，舊偏好缺欄位時補安全預設。

## 取捨

提示頁會重用正片第一個素材的開場畫面，因此畫面來源可追溯且色彩一致；這也代表提示頁可能先行看見正片的開場幾秒。此行為在 UI 中明確說明，且屬使用者要求的設計頁，不宣稱為未拍攝的旅程鏡頭。
