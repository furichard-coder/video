# ADR-0012：安插來源資料夾切換與 AI Intro 原始比例

## 狀態

已採用，v0.14.0。

## 決定

- 素材安插視窗同時列出正片與待決定素材，並提供來源資料夾篩選；使用者可在視窗內開啟 Windows 原生資料夾選擇器，唯讀加入另一個資料夾。
- 從新資料夾加入的素材只進待決定區。使用者選定素材並確認安插後，才建立安插紀錄及參與正片輸出；取消安插會回到原待決定位置。
- 選到尚未分析的待決定影片時，只對該素材延遲讀取基本 metadata，不因切換資料夾深度掃描所有來源。
- Manifest 升級為 schema 9；`MediaInsertion` 保存 `previousPlacement` 與可選的 `previousPendingIndex`，讓正片來源和待決定來源都能無損撤回。
- AI Intro 播放器使用來源 `displayWidth`／`displayHeight`（缺少時退回 coded width／height），CSS 以 `contain` 及相同比例限制播放器；任何 16:9、9:16 或其他來源比例均完整呈現，不裁切或拉伸。

## 理由

安插素材常分散在不同手機或相機資料夾，要求使用者先退出設定視窗、匯入再返回會打斷決策；但資料夾選擇本身不應等同自動排入正片。Intro 的候選審核又必須忠實顯示構圖，否則裁切或拉伸可能讓使用者錯判人物、事件與精彩程度。

## 安全與相容性

- 沿用既有來源副檔名白名單、canonical path、去重、唯讀 probe、lazy metadata、取消機制與 cache 規則。
- 不寫入、搬移或刪除來源，也不把新資料夾中的全部素材自動加入輸出。
- schema 1–8 自動遷移；既有安插視為來自正片，保持原有取消／恢復語意。
- 這項比例修正只影響 App 內 AI Intro 預覽版面，不改動來源、IN／OUT、Intro 排序或輸出 filter。
