# ADR 0041 — 已嵌入字幕的修改邊界

日期：2026-09-10  
狀態：Accepted

## 決策

- SRT 或可切換字幕軌的文字可以修改並重新匯出／封裝，不必改變影像像素。
- 目前 App 的「永久嵌入字幕」會把文字寫進每一格畫面。即使影像順序、IN／OUT 與內容說明都未改，舊字仍無法從已完成 MP4 中可靠移除或直接替換。
- 字幕文字修改後必須建立新的 MP4 版本，輸入應為無字幕乾淨影片或唯讀原始來源。不得在舊字幕上覆蓋新字，也不得覆寫上一版 MP4。
- 影像剪輯決策未改時可重用既有時間線與編輯設定，避免重新人工剪輯；但嵌入式字幕仍需要一次新的影像編碼。

## 理由

已燒錄文字是影像像素，不再是獨立字幕資料。直接覆蓋會留下舊字邊緣或背景，無法通過內容 QC。保留上一版並另產新檔，可維持版本可追溯與回復能力。
