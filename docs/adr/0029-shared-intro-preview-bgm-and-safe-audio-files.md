# ADR 0029｜共用片頭預覽、BGM 同步與安全音檔操作

日期：2026-09-07  
狀態：Accepted

## 問題

片頭設定頁只能逐段播放素材，無法精確預聽配樂頁保存的 Timeline、source IN／OUT、淡入淡出、配樂音量與素材原音比例。字幕頁建立的 480P 片頭預覽只存在 App cache，未列入片頭頁的預覽歷史；使用者也缺少一致的播放、開啟位置與複製路徑操作。字幕刪除只改畫面草稿，必須再按保存，Delete 鍵也未支援。

## 決定

- 片頭頁新增「看片頭時套用配樂」。勾選後建立 480P 共用檢看 MP4，由既有 FFmpeg 混音鏈套用 BGM Timeline、source IN／OUT、淡入淡出、各曲音量、素材原音百分比與 0.95 peak limiter。
- 是否套用配樂保存於一般使用偏好；片頭輸出頁也提供同一選項，重新開啟後沿用上次設定。
- 無配樂版本與配樂版本使用不同 cache key；key 包含片頭片段、每段輸出上限、色彩、來源狀態、BGM 完整設定、檔案大小／修改時間與預覽器版本。
- 片頭字幕 480P 與配樂同步 480P 都登錄到既有預覽成品歷史。片頭頁、字幕頁與片頭輸出頁均可播放、在檔案總管顯示及複製完整路徑。
- 每筆字幕的畫面刪除按鈕與 Delete 鍵共用同一安全流程：先說明不刪媒體，確認後立即保存新的字幕清單。游標位於輸入格、文字框或下拉選單時不攔截 Delete。
- 本機授權 MP3 可播放、開啟位置與複製路徑；IPC 只接受 manifest 內既有 track ID，再於 Main process 重新驗證絕對路徑與檔案存在。
- 不自動操控第三方 YouTube 轉檔網站、不關閉廣告或擷取音訊。YouTube 連結只保留來源／權利參考；介面提供官方 YouTube Audio Library 入口，再由使用者指定自有或已授權的本機 MP3。

## 影響

- 共用預覽為衍生檔，只供聲畫與字幕時間檢查，不作正式 Master 來源。
- 開啟配樂時若本機 MP3 尚未指定、移動或離線，預覽與輸出會安全失敗並指出曲名；關閉配樂仍可建立純素材預覽。
- 480P 共用預覽是精確混音結果，首次建立需要重新編碼；相同來源與設定再次開啟可命中 cache。
- App 不承諾第三方網站的可用性、廣告安全、音質標示或下載授權。
