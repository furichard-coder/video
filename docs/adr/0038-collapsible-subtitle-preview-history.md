# ADR-0038：字幕頁共用預覽紀錄預設收折

## 狀態

已採用（v0.47.0）

## 背景

字幕工作區需要把主要高度留給影片、字幕疊字、播放游標與文字編輯。共用片頭預覽紀錄固定展開時，會壓縮甚至遮住上方的同步預覽區域。

## 決策

- `SharedIntroPreviewHistory` 增加可選的收折模式與預設收折設定。
- 字幕頁啟用收折並預設關閉；使用者明確展開後才掛載共用 `OutputLibrary`。
- 片頭頁不啟用收折，保留原本直接顯示的工作流程。
- 收折按鈕提供 `aria-expanded` 與清楚的展開／收起名稱。

## 結果

字幕影片預覽取得穩定空間，共用成品紀錄仍可隨時使用，且沒有建立第二套播放或檔案操作邏輯。
