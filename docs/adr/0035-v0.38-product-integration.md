# ADR 0035 — v0.38/v0.39 product integration

## Decision

Use the manifest as the canonical project store and broadcast immutable `project:changed` snapshots. Every background job captures its owning project identity; project switching is rejected while work is running. Main and Intro timeline/subtitle review revisions are independent. A small shared `TimelinePlan` computes output positions instead of each feature inventing a different duration model. Subtitle preview and burn-in consume one style profile, while renderer drafts retain dirty state when an external snapshot arrives.

AI subtitle regeneration defaults to `FILL_BLANKS`; `REPLACE_AI_SCOPE` is explicit, while manual, imported and `userEdited` cues are protected. Subtitle burn-in remains a per-output opt-in and can always be unchecked before encoding.

## Compatibility and safety

Schema 14 is backward-compatible with v0.37 and older manifests. Unknown optional fields are ignored. Source paths are read-only; proxies/cache are derived and not valid output sources. Existing releases are preserved and a new version is packaged separately.

## Supersedes

Older phase documents that describe schema 13 as current or treat AI cues as draft-only are historical records. They remain unchanged for auditability; this ADR and `CURRENT_PRODUCT_SPEC.md` are the current product baseline.
