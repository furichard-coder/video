# ADR-0005：網格外部直開與不遮擋的等比例預覽

日期：2026-08-30  
狀態：Accepted

## 決策

- 網格素材卡的外部播放按鈕，左鍵立即使用既有副檔名路由開啟該素材的唯讀意圖原檔。
- 右鍵才開啟原有的 proxy／唯讀原檔選擇視窗；為鍵盤使用者提供 Context Menu 鍵與 `Shift+F10` 等價操作。
- 放大預覽以 ffprobe 的 display width／height 優先判定顯示比例，缺少時才回退 coded dimensions。
- 放大影片採 `object-fit: contain`，不裁切、不拉伸；移除會覆蓋影像的瀏覽器原生 controls，改用畫面外既有的播放／暫停、時間與 seek 控制列。

## 理由

網格的主要動作是快速觀看，依使用者選擇以原檔直接交給副檔名指定播放器；右鍵仍保留 proxy／原檔選項。瀏覽器原生控制列會浮在影片內容上，直式素材尤其容易遮住下方畫面；把控制列放在預覽容器外可保留完整構圖及原始顯示比例。

## 安全與回退

- Renderer 仍只傳 asset ID 與 `PROXY`／`ORIGINAL` 枚舉；Main process 驗證來源與播放器，不組合 shell 字串。
- 左鍵會把來源路徑交給第三方播放器，但 App 本身不修改來源；介面明確提示實際來源保護仍取決於播放器行為。
- 指定播放器遺失或啟動失敗時，沿用既有系統預設與 App 內預覽回退。
- preview 只供觀看，不得作正式輸出來源；來源檔與 metadata 保持唯讀。
