# ADR 0020：來源時間段局部放大、4K 輸出與快速片頭代理

日期：2026-09-05  
狀態：Accepted（v0.20.0）

## 決定

- 「刪除／排除部分片段」維持非破壞性編輯，並新增可持久化的 `zoomSegments`。每段保存來源 `startMs`／`endMs`、`zoomPercent` 與中心點 X／Y；倍數為 100%–400%、中心點為 0%–100%，區段不可重疊。
- 局部放大的時間基準永遠是來源時間，不是 proxy 時間或已套轉場的成片時間。縮短素材 IN／OUT 時，超出的放大區段會裁切或移除並回報調整數量。
- 正片、片頭及固定時間段輸出都從專案中的唯讀原始來源建立；proxy 只作操作預覽。FFmpeg 在既有等比／直式模糊構圖之後套用動態 zoom 與中心點，避免改寫來源。
- 固定來源時間段可手動加入目前片頭，也可獨立輸出 3840×2160 H.264/AAC MP4。低於 4K 的來源只能等比放大，不能宣稱恢復原本不存在的細節；這仍是預覽／素材候選，不是正式 Master。
- 固定時間段輸出不自動加入 BGM、字幕或片頭，避免選取素材被非預期混音或串接。它仍使用唯一 partial、成功驗證後完成、取消時安全結尾的既有原子輸出規則。

## 預覽比例

- 正片排除編輯器與片頭預覽各有獨立的顯示比例框，以 ffprobe 的 display dimensions／rotation 設定 `aspect-ratio`，畫面採 `contain`，播放列及其他操作介面位於比例框外。
- 16:9、9:16 與其他比例均完整顯示；局部放大時比例框負責裁切放大後超出的區域，UI 不占用或遮住影像。

## 快速片頭代理

- 片頭預覽不再先轉完整大型來源，只轉目前選定的來源 IN／OUT（一般 3–22 秒）。
- `clip-preview-v1` cache key 綁定來源 preview fingerprint、來源大小／修改時間、所選 IN／OUT 與預覽器版本。不同時間段不共用錯誤代理；命中時不重轉。
- FFmpeg 先嘗試本機自動硬體解碼，再安全退回軟體解碼；音訊不相容時最後可建立無聲 H.264 proxy。任一失敗都保留明確重試及外部播放器 fallback。
- 本機 NVIDIA 驅動目前不支援封裝 FFmpeg 所需的新版 NVENC API，因此不把 NVENC 編碼設為必要條件；自動硬體解碼與 `libx264 ultrafast` 是可攜、可回退的預設。

## 資料與相容性

- Manifest 升級為 schema 12。schema 1–11 開啟時為每個資產補上空的 `zoomSegments`，保留來源、排序、排除、音量、Intro、BGM 與字幕資料。
- 來源媒體、來源 metadata、既有 proxy cache、根目錄 SOP 與舊 release 均不修改或刪除。
